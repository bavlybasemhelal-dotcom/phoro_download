# phoro_download

أداة محلية لتنزيل صور المنتجات دفعة واحدة من قائمة أسماء، بواجهة عربية تدعم الاتجاه من اليمين لليسار. البحث يقبل منتجات البقالة والإلكترونيات والملابس والتجميل والأدوات وغيرها بالعربي والإنجليزي.

## التشغيل على Windows

ثبّت [Node.js](https://nodejs.org/) إصدار 20 أو أحدث، ثم افتح PowerShell في المجلد الذي تريد تنزيل المشروع فيه:

```powershell
git clone https://github.com/bavlybasemhelal-dotcom/phoro_download.git
cd phoro_download
npm.cmd install
```

بعد تثبيت المكتبات اضغط مرتين على **تشغيل.cmd**. الواجهة ستفتح في المتصفح، والخادم يعمل محليًا على جهازك. لإيقافه اضغط مرتين على **إيقاف.cmd**. يلزم اتصال بالإنترنت للبحث والتنزيل.

يمكن أيضًا تشغيل الخادم في الطرفية:

```powershell
npm.cmd start
```

افتح الرابط الذي يظهر في الطرفية، عادةً `http://127.0.0.1:4317`. للخروج من هذا التشغيل استخدم `Ctrl+C`.

## الاستخدام

1. اختر ملف TXT، أو الصق الأسماء؛ كل منتج في سطر.
2. اضغط **ابحث ونزّل الصور**.
3. راجع الصور المقترحة واضغط **اعتماد الصورة** للمنتج الصحيح.
4. استخدم **عرض البدائل** لتغيير الصورة، أو عدّل وصف البحث بعد انتهاء الدفعة أو إيقافها.
5. اضغط **افتح مجلد الصور** وارفع ملفات مجلد `ready` إلى موقعك.

يمكن كتابة وصف بحث منفصل عن الاسم باستخدام `|`:

```text
مكرونة الملكة قلم 400 جم | El Maleka penne pasta 400g
جبنة دومتي بالزيتون | Domty cheese olives
سامسونج جالاكسي A55 | Samsung Galaxy A55
حذاء أديداس سامبا | Adidas Samba OG
```

ملفات [امثلة.txt](امثلة.txt) و[امثلة متنوعة.txt](امثلة%20متنوعة.txt) متاحة للتجربة. الأداة تدعم UTF-8 وUTF-16 وWindows-1256، وتتجاهل التكرارات والسطور الفارغة والسطور التي تبدأ بـ `#`.

## البحث والدقة

البحث الافتراضي يقرأ نتائج صور Bing العامة بدون مفتاح API. قد يتوقف بسبب حدود الخدمة أو تغيير تنسيق صفحتها، ويظهر خطأ واضح عند تعذر البحث. يمكن اختياريًا إدخال مفتاح [Serper](https://serper.dev/) لاستخدام نتائج صور Google؛ التكلفة والحصص حسب حسابك. المفتاح لا يُحفظ في ملفات المشروع أو المتصفح.

**نسبة تطابق الوصف تقيس وجود كلمات البحث في وصف النتيجة وروابطها؛ ليست ضمانًا للتطابق البصري.** الأداة لا تفحص الصورة بالذكاء الاصطناعي. الأسماء العامة مثل «رز» و«حذاء»، والنتائج الناقصة، تحتاج مراجعة ولا تُنزّل تلقائيًا. الماركة والموديل أو النكهة والحجم يساعدون على الوصول إلى نتائج أدق. تأكد أيضًا من حق استخدام الصورة في موقعك.

## الملفات الناتجة

كل دفعة لها مجلد مستقل داخل `product-images` افتراضيًا:

- `review`: الصور المقترحة المنزلة.
- `ready`: الصور التي اعتمدتها، جاهزة للرفع.
- `report.csv`: الأسماء والحالات وملفات الصور وروابط المصادر.

الصور تُحفظ باسم المنتج مع رقم لمنع تصادم الأسماء، بصيغة JPG أو WebP. أقصى ضلع 1400 بكسل مع الحفاظ على النسب وبدون تكبير. الصور التي يقل أحد أضلاعها عن 180 بكسل أو تزيد عن 18 ميجا يتم رفضها. حالة الدفعات محفوظة محليًا في `.data` للاستكمال لاحقًا.

الأسماء ووصف البحث تُرسل لمحرك البحث، والصور تُطلب من مواقعها الأصلية. الأداة لا ترفع الصور إلى موقعك تلقائيًا. مجلدات البيانات والصور و`node_modules` مستبعدة من Git.

## التقنية والاختبارات

- Node.js وخادم HTTP محلي مرتبط بعنوان `127.0.0.1`.
- HTML وCSS وJavaScript للواجهة العربية.
- Sharp للتحقق من الصور وتحويلها وتصغيرها.
- JSON لحفظ الدفعات وCSV لتقارير المصادر.

```powershell
npm.cmd test
```

الاختبارات تغطي قراءة الأسماء، التطبيع العربي، المطابقة، الأسماء العامة، اختلاف الأحجام، ترتيب المصادر، رفض الروابط المحلية، تحويل الصور، وتقارير CSV.

توجد أدوات تحقق إضافية في `scripts` تستخدم صورًا فعلية من الإنترنت، وتحتاج تشغيل الخادم أولًا. فحص الواجهة يحتاج مكتبة Playwright ومتصفح Microsoft Edge، ويمكن تحديد المكتبة عبر `PLAYWRIGHT_MODULE` والمتصفح عبر `PHOTO_DESK_BROWSER`.
